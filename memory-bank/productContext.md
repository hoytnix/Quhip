# Quhip — Product Context

## Problem Domain
Actionable behavioral web analytics without invasive surveillance, cookies, heavy SDKs, or GDPR/ePrivacy consent headaches.

## UX & Capabilities
- **Zero Configuration**: Single `<script>` with `data-site` captures pageviews, active time, scrolls, and element interactions.
- **Element CTR**: True visibility denominator (`sessions clicked / sessions saw element`) using `IntersectionObserver`.
- **Suppressed Heatmaps**: Click distribution (0–99% buckets) and scroll depth (25/50/75/100%) with >= 5 session threshold.
- **First-Touch Attribution**: Channels (direct, search, social, referral, email, paid) and UTMs captured at entry and preserved.
- **Privacy by Default**: Cookieless and aggregated. Optional consent banner is strictly opt-in (all toggles unchecked, zero pre-consent transmission).
- **Dashboard**: Multi-site management, date filtering, metric cards, breakdowns, heatmaps, and goal tracking.
