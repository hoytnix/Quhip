Clear Answers

Frequently Asked Questions

Straight talk on privacy laws, edge deployment, and how Quhip works.

Do I really not need a cookie banner in the EU or UK? +
Yes, really. Both the GDPR and the ePrivacy Directive (PECR) mandate consent banners only when storing or retrieving information from a user's terminal device (e.g. cookies or local tracking IDs) for non-essential tracking, or when processing personal data like IP addresses. Quhip uses strictly ephemeral sessionStorage tokens that are destroyed when the browser tab closes, never accesses document.cookie, stores zero IP addresses (retaining only coarse country codes provided by Cloudflare headers), and suppresses low-count metrics.
How much does it actually cost to host Quhip? +
For almost every indie hacker, startup, or blog: $0 per month. Cloudflare Workers includes 100,000 requests per day for free, and Cloudflare D1 provides 5 million row reads and 100,000 row writes per day for free. Because Quhip immediately rolls up events upon ingest rather than storing raw logs, database operations remain tiny.
How is True Element CTR calculated? +
Traditional tools compute CTR as Clicks / Total Pageviews. Quhip observes when buttons or links become at least 50% visible in the user's viewport using the browser's native IntersectionObserver. The True Element CTR is calculated as Unique Sessions Clicked / Unique Sessions That Actually Saw The Element. If a user never scrolled to your footer button, their session won't skew your conversion math.
Can I track Single Page Applications (Next.js, Remix, Astro, Vue)? +
Yes. The Quhip tracking snippet automatically intercepts HTML5 history API changes (pushState and replaceState) along with popstate events. When your SPA changes client routes, Quhip automatically records the pageview, resets element visibility observers, and tracks path sequences.
How do click heatmaps protect visitor privacy? +
Quhip normalizes click coordinates into relative 0–99% buckets across the page, preventing micro-fingerprinting. Furthermore, Quhip strictly enforces small-count suppression: if a page has fewer than 5 unique sessions in the selected date window, heatmap overlay endpoints return "Not enough data" to ensure no individual visitor's path can ever be isolated.
